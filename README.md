# From Predictions to Portfolio Policies

Companion code repository for the manuscript:

> **From Predictions to Portfolio Policies: Structured Sparse Signals, Adaptive Support, and Decision-Feedback Composition**

## Release status

This private repository is currently being organized for a reproducible paper release. The initial repository contains the publication layout only; verified source code, frozen configurations, tests, and compact canonical artifacts will be added incrementally.

## Planned layout

- `src/` - canonical model, training, allocation, and evaluation implementations
- `configs/` - frozen experiment and protocol configurations
- `scripts/` - reproducible training, evaluation, and artifact-generation entry points
- `tests/` - timing, split, accounting, and implementation consistency tests
- `docs/` - method-to-code map, protocol notes, and result provenance
- `artifacts/canonical_paper_export/` - compact machine-readable paper results

Raw market data, model checkpoints, temporary outputs, and historical exploratory experiments are intentionally excluded.
